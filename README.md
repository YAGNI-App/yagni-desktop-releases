# YAGNI Code Desktop releases

Signed, notarized macOS builds of the YAGNI Code desktop app.

Assets here are published automatically by the **Desktop Release** workflow in
the main repo. Nothing in this repository is edited by hand.

- `YAGNI-Code-Desktop_aarch64.dmg` — installer, Apple Silicon
- `YAGNI-Code-Desktop_aarch64.app.tar.gz` + `.sig` — consumed by the in-app updater

Download the current build from the app, or from the
[latest release](https://github.com/YAGNI-App/yagni-desktop-releases/releases/latest).

Releases tagged `-staging.N` are prereleases used for internal testing and are
never served as "latest".
